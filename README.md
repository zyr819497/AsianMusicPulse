# AsianMusicPulse 

## 项目概述
一个基于 AI 的亚洲流行音乐趋势嗅探器。系统通过自动化数据管道，实时监测 Spotify 及各大榜单的异动，并利用 LLM 提供深度行业洞察。

## 核心工作流
1. **数据采集:** 通过 Spotify API 获取实时榜单。
2. **趋势清洗:** 过滤噪音数据，标准化歌手/歌曲信息。
3. **智能归因:** 调用 LLM 对上升榜单进行多维度分析（如：地域分布、流派风格）。
4. **报告产出:** 自动生成 Markdown 格式的趋势周报。

## 为什么这个项目很酷？
- **自动化:** 实现了“抓取-分析-报告”的全链路闭环。
- **敏锐度:** 不仅看榜单，更通过 LLM 识别“为什么火”的深层原因。
